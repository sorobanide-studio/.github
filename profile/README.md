## Built on Stellar

Settles on **Stellar** and runs its rules in **Soroban** smart contracts — transparent, inexpensive, and fast to finality.

## Overview

Edit, build, deploy, and test Soroban contracts on Stellar without leaving the browser.

## Capabilities

| | |
| --- | --- |
| **Monaco editor** | syntax highlighting and IntelliSense for Soroban |
| **Isolated environments** | Docker containers per project |
| **Deploy from the editor** | compile, inspect logs, and ship contracts to Stellar |
